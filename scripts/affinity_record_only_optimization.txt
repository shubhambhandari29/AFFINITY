RECORD ONLY - DB-ONLY OPTIMIZATION TRIAL (PREPROD)

No application, API, UI, template or permissions changes. Claims view logic is
unchanged. The Record Only view now expresses policy/claim eligibility and the
financial NOT EXISTS check before descriptive enrichment. Its policy date
predicate no longer casts the source column. Jan 1 remains excluded completely.
Output columns, grouping, current-version checks and NULL-feature semantics
are retained. A CTE is NOT a materialized table and does not force join order.
SQL Server may choose the same plan; do not assume this makes the query faster.

-- Compare complete rows AND duplicate counts. JSON preserves named field
-- values and provides one comparable representation for each output row.
SELECT (SELECT b.* FOR JSON PATH, INCLUDE_NULL_VALUES, WITHOUT_ARRAY_WRAPPER)
    AS RowData INTO #BeforeJson FROM #BeforeRecordOnly b;
SELECT (SELECT a.* FOR JSON PATH, INCLUDE_NULL_VALUES, WITHOUT_ARRAY_WRAPPER)
    AS RowData INTO #AfterJson FROM #AfterRecordOnly a;
SELECT RowData, COUNT_BIG(*) AS Copies FROM #BeforeJson GROUP BY RowData
EXCEPT
SELECT RowData, COUNT_BIG(*) FROM #AfterJson GROUP BY RowData;
SELECT RowData, COUNT_BIG(*) AS Copies FROM #AfterJson GROUP BY RowData
EXCEPT
SELECT RowData, COUNT_BIG(*) FROM #BeforeJson GROUP BY RowData;

Both difference grids must be empty. Run the comparison on the same Eastern
calendar day: RO System Date changes at midnight. Source changes during testing
can also produce differences and must be investigated rather than ignored.
Share counts, difference grids, and both Messages timing/IO outputs.
